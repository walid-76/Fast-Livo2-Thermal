###########################################################################################

How to run the main package to output raw therma data 16 bit or 8 bit:
ros2 launch flir_boson_usb boson.launch.py

###########################################################################################

to run the thermal processing :
ros2 run flir_boson_usb boson_camera_node --ros-args -p dev:="/dev/video0"

###########################################################################################

How to run the Lidar package for the mid 360:
ros2 launch livox_ros_driver2 rviz_MID360_launch.py   with rviz
ros2 launch livox_ros_driver2 msg_MID360_launch.py    for slam 


###########################################################################################

how to run the intel release d455 rgb camera only
ros2 launch realsense2_camera rs_launch.py enable_color:=true enable_depth:=false enable_infra1:=false enable_infra2:=false
